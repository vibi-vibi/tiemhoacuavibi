# 🌸 Tiệm Hoa Của Vibi - Giao Diện Website Tĩnh Cao Cấp

Chào mừng bạn đến với mã nguồn chính thức của **Tiệm Hoa Của Vibi** (`tiemhoacuavibi.com`). Đây là dự án website tĩnh giới thiệu và kinh doanh hoa tươi nghệ thuật, quà tặng tinh tế đơm hoa kết ý theo yêu cầu.

## 🎨 Thông Tin Giao Diện & Thương Hiệu
- **Tên thương hiệu:** Tiệm Hoa Của Vibi
- **Slogan:** Trao Hoa Gửi Yêu Thương
- **Màu sắc chủ đạo:** Hồng cánh sen lãng mạn, Trắng hồng pastel ngọt ngào, Chữ xám đen đậm thanh lịch.
- **Phong cách thiết kế:** Tạp chí nghệ thuật Châu Âu đan xen hình ảnh sống động, bố cục lưới (Grid) đối xứng cân bằng hoàn hảo.

## 📂 Cấu Trúc Thư Mục Dự Án
- `/css/styles.css` — Quản lý toàn bộ giao diện, bảng màu `:root` và font chữ hệ thống.
- `/images/` — Nơi lưu trữ hình ảnh sản phẩm nội bộ sắc nét (`hoahong.jpg`, `huongduong.jpg`, `hoaTulip.jpg`...).
- `/js/main.js` — Xử lý các hiệu ứng tương tác cuộn trang và menu điều hướng di động.
- `index.html` — Trang chủ ngập tràn sắc hoa với lưới 8 sản phẩm tuyển chọn.
- `hoa-tuoi.html` — Danh mục các thiết kế hoa tươi nhập mới mỗi ngày.
- `ve-chung-toi.html` — Trang kể câu chuyện thương hiệu đầy cảm xúc kết hợp hình ảnh đan xen so le sang trọng.

## 🚀 Cấu Hình SEO & Hệ Thống Hoàn Chỉnh
- `sitemap.xml` — Sơ đồ 9 trang con cốt lõi tối ưu hóa cho Googlebot quét dữ liệu.
- `robots.txt` — File điều hướng robot tìm kiếm hợp pháp, bảo mật thư mục mã nguồn.
- `site.webmanifest` — Cấu hình cài đặt trang web thành ứng dụng (App) di động mượt mà trên điện thoại.
- Gắn sẵn mã đo lường **Google Analytics** (`G-FN4CJG2KSM`) theo dõi lượng khách truy cập thời gian thực.

## 🛠️ Hướng Dẫn Vận Hành Local
1. Mở thư mục dự án bằng phần mềm **Visual Studio Code**.
2. Click chuột vào file `index.html`.
3. Nhấn nút **Go Live** ở góc dưới cùng bên phải màn hình để khởi chạy trang web trên trình duyệt nội bộ (`localhost:5500`).
